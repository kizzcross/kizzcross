## About Me

I'm currently working at **BaseHit** as a **Fullstack Developer**.

My main focus is backend development, building **APIs, integrations, automation workflows, data-driven applications and internal systems** mainly with **Python, Django and PostgreSQL**.

I also work with **AI and LLM-powered applications**, using **LangChain** and **LangGraph** to build agents, workflows, integrations and automated processes.

On the frontend, I mainly work with **React and TypeScript**, building interfaces that connect all of that backend chaos together.
